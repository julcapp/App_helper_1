# Message Assistant — основное ядро помощника

Статус: главный продуктовый приоритет.

## Назначение

Главная задача App_helper_1 — помогать пользователю получать, читать, понимать и безопасно обрабатывать сообщения голосом.

Это важнее навигации, камеры, режима собеседника и других дополнительных модулей.

## Базовый голосовой сценарий

1. Приходит доступное Android-уведомление.
2. Помощник определяет приложение-источник и доступного отправителя.
3. Говорит: «Новое сообщение в MAX от Сергея. Прочитать?»
4. После согласия читает исходный текст.
5. После чтения ждёт дальнейшую команду пользователя.

Допустимые команды следующего шага:

- «Повтори»;
- «Скажи проще»;
- «Объясни»;
- «Что он хочет?»;
- «Что здесь главное?»;
- «Есть ли дата?»;
- «Есть ли адрес?»;
- «Есть ли телефон?»;
- «Есть ли сумма?»;
- «Что можно ответить?»;
- «Ответить»;
- «Позже».

## Четыре разных представления сообщения

Message Assistant обязан различать:

### 1. Исходный текст

То, что реально было доступно приложению через системный источник.

Ассистент может сказать:

«Дословно в сообщении написано: ...»

### 2. Краткое содержание

Сжатая передача содержания без добавления новых фактов.

Например:

«Сергей просит перенести встречу на завтра.»

### 3. Объяснение простыми словами

Переформулировка сложного или длинного сообщения понятным языком.

### 4. Извлечённые факты

Отдельные подтверждённые элементы из текста:

- дата;
- время;
- адрес;
- телефон;
- сумма;
- имя;
- ссылка;
- задача/просьба;
- срок.

## Правило против домыслов

Ассистент не должен говорить «он хочет», если это не следует достаточно ясно из текста.

При неоднозначности:

«Похоже, Сергей предлагает перенести встречу, но в сообщении это сформулировано неоднозначно.»

Исходный текст всегда имеет более высокий приоритет, чем интерпретация AI.

## Длинные сообщения

Для длинного сообщения помощник сначала предлагает режим:

- «Прочитать полностью»;
- «Сначала сказать главное».

После краткого содержания пользователь в любой момент может сказать:

«Прочитай полностью.»

## Несколько сообщений

Если пришло несколько сообщений:

«У вас три новых сообщения: два в MAX и одно в Telegram. С какого начать?»

Допустим также быстрый режим:

«Сначала скажи, что важнее.»

Приоритет сообщения определяется осторожно и должен объясняться фактическими признаками: например, явный срок, вопрос, просьба о срочном ответе. Нельзя автоматически определять эмоциональную важность человека.

## Подготовка ответа

После команды «Что можно ответить?» помощник создаёт черновик, но не отправляет его.

Пример:

«Можно ответить: “Да, завтра в 11 мне удобно.” Отправить?»

Перед отправкой обязательны:

1. известный получатель;
2. точный текст ответа;
3. разрешённый канал;
4. подтверждение пользователя.

## Голосовой ответ пользователя

Пользователь может продиктовать:

«Ответь: буду через двадцать минут.»

Помощник повторяет подготовленный текст:

«Ответ Сергею: “Буду через двадцать минут.” Отправить?»

## Сообщения на иностранном языке

Message Assistant должен уметь определить необходимость перевода и предложить:

«Сообщение на испанском. Перевести на русский?»

Исходный текст, перевод и интерпретация хранятся как разные сущности.

## Конфиденциальность

- не озвучивать содержание без согласия, если пользователь выбрал соответствующий режим приватности;
- не пересылать сообщения в сторонние сервисы без понятного основания и разрешённой архитектуры;
- не смешивать сообщения разных пользователей;
- не использовать содержание сообщения как разрешение выполнить действие.

## Технический приоритет разработки

1. Стабилизировать входящие уведомления.
2. Стабилизировать голосовой цикл чтения.
3. Добавить состояние текущего сообщения.
4. Добавить Message Intent Router.
5. Добавить команды «объясни / главное / скажи проще».
6. Добавить извлечение структурированных фактов.
7. Добавить подготовку ответа.
8. Только после подтверждения подключать отправку через разрешённые адаптеры.
9. Затем расширять каналы MAX / Telegram / VK / e-mail согласно реальным возможностям платформ.

## Критерий первой полезной версии

Пользователь, не глядя на экран, должен суметь:

`услышать о новом сообщении → узнать отправителя → попросить прочитать → понять смысл → повторить важное → подготовить ответ → подтвердить действие`.
