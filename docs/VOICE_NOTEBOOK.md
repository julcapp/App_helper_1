# Мои мысли — голосовой блокнот

Статус: второй основной пользовательский модуль после Message Assistant.

## Назначение

Модуль помогает пользователю голосом сохранять мысли, идеи и рабочие заметки, переводить речь в текст, возвращаться к записям, дополнять их и передавать другим людям.

## Базовый сценарий

1. Пользователь говорит: «Запиши мысль», «Запиши идею», «Открой блокнот» или «Добавь к моей идее про …».
2. Помощник записывает голос только после явной команды пользователя.
3. Аудиофрагмент и его транскрипция связываются с одной заметкой.
4. Исходная транскрипция сохраняется отдельно и не заменяется AI-редакцией.
5. Пользователь может позже открыть заметку, прослушать/прочитать её, дополнить или отредактировать.
6. Для передачи другому человеку помощник сначала готовит текст и показывает/озвучивает его пользователю.
7. Отправка выполняется только после явного подтверждения и только через разрешённый канал.

## Структура записи

`Папка → Заметка/идея → исходное аудио → транскрипция → AI-представления → дополнения → история версий → получатели`

Минимальные поля заметки:
- id;
- папка;
- заголовок;
- дата создания;
- дата последнего изменения;
- исходные аудиофрагменты;
- исходная транскрипция каждого фрагмента;
- объединённый текст;
- краткое содержание;
- статус;
- теги;
- история изменений.

## Папки по умолчанию

- Идеи;
- Работа;
- Личное;
- На потом.

Пользователь может создавать свои папки голосом.

## Голосовые команды

- «Запиши новую мысль»;
- «Сохрани это как идею»;
- «Добавь это к идее про …»;
- «Какие идеи я записал сегодня?»;
- «Что я записывал про …?»;
- «Напомни мои незаконченные идеи»;
- «Прочитай последнюю идею»;
- «Сделай из этой идеи нормальный текст»;
- «Подготовь это для отправки …».

## AI-обработка

AI может создавать только производные представления:
- очищенный текст;
- краткое содержание;
- структурированный вариант;
- список задач;
- письмо;
- сообщение для мессенджера.

Исходная аудиозапись и исходная транскрипция имеют более высокий приоритет и не должны перезаписываться AI-версией.

## Возврат к идеям

Пользователь может включить периодические предложения вернуться к старым или незавершённым идеям. Такая функция отключаема. Помощник не должен самовольно изменять содержание заметки.

## Передача записей

Первый универсальный механизм Android — системный Share Sheet для передачи подготовленного текста в установленный мессенджер или почтовый клиент.

Прямые интеграции с MAX, Telegram, VK и e-mail подключаются отдельно только там, где есть разрешённые API и корректная модель авторизации.

Перед отправкой обязательны:
1. выбранная заметка;
2. выбранная версия текста;
3. известный получатель/канал либо системный выбор приложения;
4. финальное подтверждение пользователя.

## Приоритет разработки

Voice Notebook не должен задерживать завершение Message Assistant. Порядок:
1. закончить AI-анализ сообщений;
2. добавить подготовку и подтверждение ответа;
3. затем реализовать минимальный Voice Notebook: запись → транскрипция → хранение → дополнение → Share Sheet;
4. после этого добавить AI-редакцию заметок и напоминания о старых идеях.
