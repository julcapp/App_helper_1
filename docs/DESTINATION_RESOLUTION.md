# Однозначное подтверждение точки назначения

## Цель

Помощник не должен строить маршрут по неоднозначной фразе пользователя. Перед началом навигации место назначения должно быть однозначно определено и подтверждено пользователем голосом.

## Базовый сценарий

Пользователь: «Мне нужно на кладбище».

Если в текущем городе найдено несколько подходящих мест, помощник уточняет:

«В городе найдено несколько кладбищ. Какое вы имеете в виду: Новое кладбище, кладбище на Пушкинской улице или кладбище рядом с храмом ...?»

Пользователь может ответить:

- названием;
- улицей;
- районом;
- известным ориентиром;
- храмом/церковью;
- другим отличительным признаком.

После выбора помощник повторяет конкретную точку:

«Подтвердите место назначения: Новое кладбище, улица Пушкинская, рядом с храмом .... Это нужное место?»

Только после ответа «да» разрешено строить маршрут.

## Обязательные правила

1. Не считать общие слова «кладбище», «вокзал», «храм», «больница», «рынок», «станция» достаточными, если в городе есть несколько вариантов.
2. При нескольких совпадениях перечислять 2–3 наиболее различимых варианта.
3. Использовать для различения название, адрес, улицу, район и ориентиры, которые реально передал источник поиска мест.
4. Не придумывать ориентиры и не подменять адрес предположением.
5. Даже при одном найденном совпадении перед стартом маршрута запросить короткое подтверждение пользователя.
6. После подтверждения сохранить выбранное место в истории пользователя.
7. При повторном запросе в будущем можно предложить ранее подтверждённое место: «В прошлый раз вы ездили на Новое кладбище. Вы имеете в виду его?»
8. Пользователь всегда может ответить «нет» и задать другое место.

## Связь с городским контекстом

Поиск выполняется только внутри подтверждённого текущего города/региона пользователя. Если город ещё не задан, сначала спрашиваем город, затем уточняем точку назначения.

Последовательность:

`город → запрос места → поиск вариантов → голосовое уточнение → подтверждение → сохранение → построение маршрута`.

## Хранение

`DestinationHistoryStore` хранит последние подтверждённые пользователем места. Это позволяет учитывать повторные поездки, но прошлый выбор не является разрешением автоматически использовать ту же точку без подтверждения в новом маршруте.
