## TalkBack: сценарии
1. Включить TalkBack в настройках Android. Открыть приложение. Фокус сначала должен достигать заголовка «Мой помощник», затем «Говорить».
2. Свайпами последовательно пройти все элементы. Не должно быть пустых, дублированных или непонятных фокусов.
3. Двойное нажатие на «Говорить» начинает голосовую команду при разрешённом микрофоне; без разрешения появляется системный запрос.
4. При входящем уведомлении TalkBack должен прочитать источник и отправителя, а по выбору — кнопку «Прочитать вслух». Содержание сообщения не должно самовольно озвучиваться при включённом конфиденциальном режиме (режим ещё требует реализации).
5. Вкладка «Помощь и дополнительные функции» открывает и закрывает блок; удостовериться, что порядок фокуса ожидаемый.
6. При ошибке STT появляется понятный текст ошибки и действие «Попробовать снова».
7. Проверить навигацию по заголовкам TalkBack. У каждого элемента управления должно быть понятное имя, статус и действие.
8. Проверить двойное озвучивание: синтез речи приложения и TalkBack не должны перебивать друг друга (требует аудио-фокуса и тестов с реальными устройствами).

## Увеличение текста и обзор
- Масштаб шрифта Android 100%, 150%, 200%.
- Минимальная ширина экрана ~320dp, портрет и альбомная ориентации.
- Никакой обрезки кнопок; в режиме больших шрифтов используется вертикальная прокрутка.
- Нажатие по кнопке не требует точности, зона минимум 72dp по высоте.
- Проверить высокий контраст, светлую/тёмную темы, динамические цвета и системную инверсию.
- Проверить взаимодействие без голоса, используя TalkBack, Switch Access и обычные касания.

## Голосовой контур: матрица
| Событие | Ожидаемое поведение |
| --- | --- |
| Микрофон запрещён | понятная причина и возможность открыть разрешение |
| Пользователь молчит | повторить вопрос/дать кнопку, не сбросить работу |
| Синтез речи прерван звонком | корректный аудио-фокус, восстановление по запросу |
| Несколько уведомлений подряд | очередь, не потерять текущее сообщение |
| Распознавание слова неоднозначно | уточнение, а не выполнение действия |
| Интернет выключен | локальный путь чтения при доступном TTS, объяснить недоступность AI |
| AI-шлюз ответил ошибкой | сохранить оригинал, предложить повторить |
| «Ответить Сергею» | только черновик, без отправки |
| «Отправить» | прочитать получателя, канал, точный текст, запросить подтверждение |
| Новое уведомление на экране блокировки | учесть режим конфиденциальности |
| Подключена гарнитура | контролировать аудиомаршрут и приватность |

## Полевые UX-тесты
Провести наблюдаемые интервью и испытания на разных группах: слабовидящие, незрячие, пожилые начинающие; не делать выводы об удобстве по одному дизайнерскому просмотру. Цель: минимум 5 участников на группу, если возможно. Записывать выполнение задач, ошибки, время, вопросы и пользовательские формулировки. Не собирать реальные переписки без отдельного согласия.
