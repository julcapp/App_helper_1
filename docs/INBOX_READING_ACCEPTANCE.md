# Проверка первого этапа «Входящие и чтение»

## Возможности и границы
Локальная очередь до 50 доступных событий, обновления, отложенные, чтение по кнопкам/голосу. MAX, Telegram, WhatsApp, VK, почта и другие приложения — через их Android-уведомления; это не полный архив аккаунта. Прямые почтовые подключения, OCR, вложения и синхронизация истории пока не реализованы. Содержимое остаётся в памяти процесса. Журнал — метаданные; изменение Android-статуса прочтения и отправка сообщений не выполняются.

## На реальном устройстве — ещё не выполнено
- Включить доступ к уведомлениям; отправить тестовые сообщения самому себе из MAX/Telegram/WhatsApp/VK и тестовое письмо. Сравнить доступный текст с уведомлением.
- Повтор/обновление одного уведомления: не плодить дубли, новый текст доступен; второе событие не прерывает активный снимок.
- Получить MessagingStyle-пачку, групповую сводку, скрытое превью, вложение без текста; не выдавать сводку/название приложения за полный текст.
- Прочитать входящие; «кто написал», «повтори», «медленнее», «следующее», «позже», «читай всё по очереди»; остановить кнопкой во время речи. Голосовые команды подаются через «Говорить», непрерывного фонового микрофона нет.
- Прервать речь звонком, блокировкой, уходом из приложения, потерей аудиофокуса; не возобновлять приватную речь автоматически, не отмечать незавершённый текст прочитанным.
- Отключить источник в дополнительных функциях: очистить его очередь, прекратить чтение; снова включить и проверить новые уведомления.
- Из браузера передать выделенный текст через «Поделиться»/обработку выделения. Переданная ссылка остаётся только ссылкой, полная страница не загружается.
- Включить службу «Чтение открытого экрана» в Android Accessibility, назначить системную кнопку; открыть веб-страницу и нажать. Повторное нажатие останавливает; без нажатия ничего не собирается. Проверить поля пароля, закрытые окна, длинную страницу и блокировку. Служба не заменяет TalkBack; проверить совместную работу и выбор ярлыка.
- Проверить TTS без интернета с установленным русским голосом; STT — отдельно при наличии локального движка/языка. Не обещать offline STT на всех телефонах.
- Пройти основные действия без микрофона с TalkBack и при 200% шрифте на узком экране.
