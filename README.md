# App_helper_1

Помощник для слабовидящих и пожилых людей.

## Концепция

`App_helper_1` — мобильное приложение и персональный голосовой AI-агент для управления смартфоном и получения понятных голосовых ответов.

Основная идея: **один общий AI Agent Core, но отдельная персональная память, настройки, интересы и разрешения для каждого пользователя**.

## Для кого

- слабовидящие и незрячие пользователи;
- пожилые люди;
- пользователи, которым сложно освоить обычный сенсорный интерфейс;
- люди с ограниченной моторикой;
- пользователи, которым удобнее управлять смартфоном голосом.

## Платформы

- Android — первая и наиболее функциональная платформа;
- iOS — отдельный платформенный адаптер с учётом ограничений Apple;
- MAX — канал интеграции, а не основной интерфейс;
- далее возможны Telegram, VK, e-mail и другие каналы.

## Основные способности

1. Слышать — распознавать речь пользователя.
2. Говорить — озвучивать события и ответы.
3. Читать — сообщения, уведомления, экран и документы.
4. Видеть — использовать камеру для описания окружающей среды и чтения текста.
5. Помнить — вести персональную базу знаний пользователя.
6. Действовать — звонки, сообщения, контакты и разрешённые действия в приложениях.
7. Ориентировать — GPS, маршруты и помощь в поездках.
8. Переводить — голосовой и текстовый перевод, в первую очередь русский ↔ испанский.
9. Обучать — голосовой мануал, повторное обучение и контекстные подсказки.
10. Общаться — персональный голосовой собеседник по интересам пользователя.

Над всеми функциями работает отдельный контур безопасности: разрешения, подтверждения чувствительных действий, приватность и контроль памяти.

## UX-принципы

- голос — основной способ управления;
- один вопрос — одно решение;
- минимум многоуровневых меню;
- крупные зоны нажатия и высокий контраст;
- команды «Повтори», «Медленнее», «Я не понял» доступны всегда;
- чувствительные действия выполняются только по правилам пользователя;
- AI понимает естественные формулировки, а фактическое действие выполняет проверяемый Action Manager.
