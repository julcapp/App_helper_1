# App_helper_1

Помощник для слабовидящих, пожилых и voice-first пользователей.

## Главный акцент

Основная ценность первой рабочей версии — **голосовой помощник по чтению, расшифровке и объяснению сообщений и уведомлений**.

Пользователь должен суметь, практически не глядя на экран:

`услышать о новом сообщении → узнать отправителя → попросить прочитать → понять смысл → повторить важное → подготовить ответ → подтвердить действие`.

Навигация, камера, перевод, собеседник и заботливые подсказки остаются важными дополнительными модулями, но не должны задерживать стабилизацию Message Assistant.

Подробная спецификация: `docs/MESSAGE_ASSISTANT.md`.

## Концепция

`App_helper_1` — мобильное приложение и персональный голосовой AI-агент для управления смартфоном и получения понятных голосовых ответов.

Основная архитектурная идея: **один общий AI Agent Core, но отдельная персональная память, настройки, интересы и разрешения для каждого пользователя**.

## Для кого

- слабовидящие и незрячие пользователи;
- пожилые люди;
- пользователи, которым сложно освоить обычный сенсорный интерфейс;
- люди с ограниченной моторикой;
- пользователи, которым удобнее управлять смартфоном голосом.

## Платформы

- Android — первая и наиболее функциональная платформа;
- iOS — отдельный платформенный адаптер с учётом ограничений Apple;
- MAX — канал интеграции, а не основной интерфейс;
- далее возможны Telegram, VK, e-mail и другие каналы.

## Основные способности

1. **Читать и объяснять** — сообщения, уведомления, экран и документы. Это главный приоритет MVP.
2. Слышать — распознавать речь пользователя.
3. Говорить — озвучивать события и ответы.
4. Помнить — вести разрешённый персональный контекст пользователя.
5. Действовать — готовить ответы, звонки, контакты и другие разрешённые действия с подтверждением.
6. Ориентировать — GPS, маршруты, общественный транспорт и помощь в поездках.
7. Переводить — голосовой и текстовый перевод, в первую очередь русский ↔ испанский.
8. Видеть — использовать камеру для описания окружающей среды и чтения текста.
9. Обучать — голосовой мануал, повторное обучение и контекстные подсказки.
10. Общаться — персональный голосовой собеседник по интересам пользователя.

Над всеми функциями работает отдельный контур безопасности: разрешения, подтверждения чувствительных действий, приватность и контроль памяти.

## UX-принципы

- голос — основной способ управления;
- один вопрос — одно решение;
- сначала исходный текст сообщения, затем его объяснение;
- AI не выдаёт интерпретацию сообщения за дословное содержание;
- минимум многоуровневых меню;
- крупные зоны нажатия и высокий контраст;
- команды «Повтори», «Медленнее», «Я не понял» доступны всегда;
- чувствительные действия выполняются только по правилам пользователя;
- AI понимает естественные формулировки, а фактическое действие выполняет проверяемый Action Manager.

## Текущий технический фокус

1. Стабилизировать получение Android-уведомлений.
2. Стабилизировать голосовой цикл «новое сообщение → прочитать?».
3. Добавить команды «объясни», «скажи проще», «что здесь главное».
4. Извлекать из сообщения даты, время, адреса, телефоны, суммы и явные просьбы.
5. Добавить подготовку ответа без автоматической отправки.
6. После этого подключать разрешённые адаптеры отправки и расширять каналы сообщений.

Подробные решения и дорожная карта фиксируются в каталоге `docs/`.
