# App Helper AI Gateway

Серверный шлюз для смыслового анализа входящих сообщений.

## Почему отдельный сервер

`OPENAI_API_KEY` нельзя помещать в Android APK: ключ можно извлечь из клиентского приложения. Android обращается к нашему шлюзу, а шлюз — к OpenAI Responses API.

## Переменные окружения

- `OPENAI_API_KEY` — обязательно;
- `OPENAI_MODEL` — необязательно, по умолчанию `gpt-5.6-luna`;
- `PORT` — необязательно, по умолчанию `8080`.

## API

### GET /health

Возвращает состояние сервиса без раскрытия ключа.

### POST /v1/message-analysis

Вход:

```json
{
  "message": "Завтра в 11 встречаемся у офиса. Подтверди, пожалуйста."
}
```

Выход:

```json
{
  "summary": "Встреча назначена на завтра в 11 у офиса.",
  "plainExplanation": "Автор сообщает место и время встречи и ждёт подтверждения.",
  "explicitRequest": "Подтвердить встречу.",
  "uncertainty": "low"
}
```

## Безопасность

- `store: false` устанавливается в запросе к Responses API;
- содержание сообщения трактуется как данные, а не как инструкция модели;
- шлюз не имеет функций отправки сообщений, звонков, изменения контактов или иных действий;
- до публичного развёртывания требуется добавить пользовательскую аутентификацию/авторизацию и rate limiting;
- не публиковать `OPENAI_API_KEY` в GitHub, APK, логах или клиентской конфигурации.
